# Issue #25：公积金专区与业务政策报告

## 页面结构

```text
每日新闻 /summary
公积金专区
├─ 每日新闻 /provident-fund/news
├─ 地区浏览
│  ├─ 新闻浏览 /policy/regions
│  └─ 地区 AI 报告 /policy/region-report
├─ 业务类型浏览
│  ├─ 新闻浏览 /provident-fund/business
│  └─ 业务政策 AI 报告 /provident-fund/business-report
└─ 扬州公积金专区
   ├─ 现行政策编辑 /policy/current
   └─ 周报政策对比 /policy/comparison
```

全站每日新闻仍可显示公积金和其他关键词，使用原有通用字段。专区每日新闻固定公积金、默认昨天，显示地区和业务标签；标签跳转保留日期和其他维度条件。地区、业务浏览默认最近30天，分别突出地区树和业务目录。四个旧政策页面 URL 保留。

`config/navigation.json` 是菜单和叶子权限的共同定义。父分组按可见子页面派生，采用独立折叠状态；专区使用浅色边框，保持既有整体风格。移动端侧栏位于顶部栏下方，可通过顶部按钮关闭。

## 权限及已有用户

继续使用 `role + keywords + routes`。管理员按 role 拥有完整访问；受限用户需同时具备“公积金”关键词和具体叶子路由。浏览、报告、扬州功能分别授权，父分组不授予权限。

`config/runtime/users.json` 存在时，权限以它为准。读取和登录不再自动补回内置账号的旧路由。旧用户不会自动获得三个新增入口：管理员在用户管理页勾选后保存即可。页面启动通过 `/api/auth/me` 刷新资料；401 清理会话，公积金请求遇到403时刷新权限。管理自己的权限后也刷新。空权限用户显示说明，不发生循环跳转。

公积金新闻、预览、生成、PDF及扬州工具接口均执行对应叶子权限。此变更不代表平台全部旧接口已经实现逐行数据隔离。

## 数据口径

- 固定关键词为“公积金”，评分至少3；参数不能改写这两个条件。
- 日期为 `fetchdate` 采集日期，不等于发布或生效日期。保留 mysql2 DATE 的本地日历日期，避免 UTC 转换导致少一天。
- 一级业务为缴存、提取、贷款、其它；身份为 `(level1, level2)`。别名按 `news_table=scored_news` 读取，可沿链归并；循环、错误 JSON 和结构异常标为异常，不写回数据库。
- NULL 为待标注，空数组为未识别，均不视为“其它业务”。页面显示标注覆盖统计。
- 已知地区别名归一化，“全国”与全部地区分开；省内合计包括省级和下属城市，“省级新闻”只指省级本身。吉林市保持城市身份。无法识别的地区进入未识别计数，原始文本仍保留。
- 同维度 OR，不同维度 AND；新闻按 ID 去重后排序、分页。父分类数量和平均分按新闻 ID 集合计算。新闻可属于多个分类，因此分类数量相加可能超过总数。
- 地区 facet 忽略地区选择，业务 facet 忽略业务选择，各自保留另一维度条件。已选零计数项仍可取消。
- 查询使用独立、可重复读的只读事务：候选元数据 → 精确筛选 → 分页 → 本页正文。连接在 finally 释放。

边界：区间1–366天；元数据最多10,000条；每页1–100条；报告候选最多200条；最终 Prompt 最多180,000字符。超限明确报错，不静默截断。别名表缺失时显示降级提示；其他 SQL 错误不伪装成空结果。网页请求不建表、不建索引、不补标。

## 报告与 PDF

地区报告支持1–10个地区，可生成时间线或通用比较；业务报告要求一个一级或精确二级业务、2–10个地区，至少两个地区有纳入材料。两种用途由各自接口固定，客户端不能通过 `reportKind` 切换权限。

预览展示候选、自动纳入理由、材料类别及地区覆盖，允许人工纳入/排除。业务报告把指南/问答视为既有规则，排除企业财务公积金。多地区、多标签属于新闻级属性，不能据此推断每项政策适用于所有组合。

生成前在只读事务中重新取得材料并核对 `previewHash`。正文、摘要、标签、别名、筛选或类型改变时返回409，要求重新预览。外部 ID 和非布尔人工调整被拒绝。生成消息中每篇新闻只出现一次，保留正文、摘要、标签、原始地区、来源及链接。快照包含实际纳入来源、覆盖、Prompt 内容 hash 和模型名。

业务报告采用五部分结构，关键事实使用 `[N新闻ID]`。服务端检查章节、空输出和引用 ID，无法证明事实语义正确；真实模型质量仍需另行验收。前端引用可定位到来源列表。

PDF 使用生成响应中的签名快照，不重新组装当前预览。服务端核对签名和报告类型；修改过的正文或快照无法导出。报告条件、模板、补充要求或人工选择改变后旧报告失效。PDF 展示专题、日期、地区、模型、Prompt 和来源 ID；仅 http/https 原文链接可点击。旧 PDF 模板调用不传业务字段仍可渲染。
