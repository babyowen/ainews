## 原因与修复

### 章节标题

实际历史正文中，养老的三个章节均缺少 Markdown 标记，公积金首章缺少标记，烟草服务银行使用 `#`。原渲染器按普通 Markdown 处理，因此产生普通正文、18pt 标题和 24pt 标题混用。

周报 PDF 现在独立处理章节：将已知历史章节的独立纯文本、整行加粗及缺少空格的标题恢复为 `h2`；将显式的顶层中文编号章节统一为 `h2`。标题仍为 18pt、700 字重，正文仍为 12pt。正文中提及章节、列表、引用、表格和代码不会被误改为章节。

兼容处理仅作用于周报 PDF，不改写数据库里的历史 Markdown，也不改变政策报告的通用 Markdown 渲染器。烟草服务银行继续保留两个章节，不强制补出第三章。

### 分页

原模板要求整个列表、引用、表格或代码块不跨页。块内容较长时被整体推到下一页，导致上一页留下大块空白。

现在允许这些容器自然跨页，尽量保持单条短新闻和表格单行完整；嵌套列表的父条目允许跨页，超长条目仍可自然拆分。跨页表格重复表头。另小幅收紧行距和段间距，保持 A4、原页边距及正文字号。
