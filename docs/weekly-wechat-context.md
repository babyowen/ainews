# 官微周报来源上下文

已上线。2026-11-15首轮自动周报已携带15篇官微的地域信息；排版和地区归属改善，但内容质量未完全通过，最新结论与暂停范围见[阶段交接](government-wechat-20261115-handoff.md)。

仅当本次报告专题为「江苏机关事务」、文章来源接口为 `极致了api`、微信长链接的账号身份存在于已核验清单时，在每篇新闻前独立附加发布账号、账号辖区和账号层级。标题、正文、已有短摘要和数据库字段保持原样。

`services/weeklyReportNews.cjs` 负责共享组装，手动三个生成入口（含流式）、后端消息预览、自动周报以及潜在客户模板均使用它。查询多读取已有的 `sourceapi` 列。短摘要和全文模式均携带来源上下文；正文少于500字而直接采用原文的文章也能获得地域背景。

来源规则只追加到含有匹配官微的当次模型 system 消息。所有现有 `config/` 提示词和 `config/runtime/` 自定义模板不改写、不保存新版本；未匹配账号不追加来源推断规则，其他专题不追加任何本专题规则。已有的日期规则处理保持原行为。新闻正文明确的主体与地点关系优先，转载、引语和跨地区交流不得套用账号辖区，指代含糊时不猜测，也不从专题名称推断发生在江苏。

## 来源映射

`config/government-wechat-sources.json` 是采集端 `babyowen/serp_news` 的已核验清单及 `verified_source_context` 输出的只读版本快照，包含38个启用账号；停用的宁波号不在其中。文件记录源提交、清单路径和SHA-256、解析器版本及SHA-256。来源名单改变时，应从同一采集端注册表和解析器重新导出并审核，不能按昵称猜测或手写新增地区。周报运行时不跨服务器读取采集端。

匹配依赖 `mp.weixin.qq.com/s` 的唯一 `__biz`、`mid`、`idx` 参数；未知、停用或身份冲突的文章保持原处理方式。客户端提供的账号昵称、地区或 `source_context` 字段不用于建立映射。

## 地域表达和分组补充（2026-11-14）

`applyWeeklyNewsRules` 在当次请求尾部增加两种限定规则：

- 含匹配官微时：逐事项消解“我局、我省、我市”等，再写可确认的地区与主体。跨地交流分清主体所在地与访问地；省级账号的下属城市案例、国家号转载和引语均按实际主体判断。映射没有法定机构全称，不能凭账号昵称补造，只能使用有依据的中性称谓。
- 所有本专题的非空新闻请求（含纯官网材料）：保留江苏本地、国家政策、省外借鉴三个栏目，每栏内采用“业务分类父列表 → 缩进事项子列表”，每类只出现一次；每条以加粗的可确认地区起首，全国政策用“全国”。仅合并分类，保留不同地区独立事项，不跨主栏目合并，不改变既有日期、选材和去重要求。

未匹配账号的本专题素材逐条标注“本条无已核验账号信息”，明确不得沿用相邻新闻地区；这是否定核验标识，不补造地区。综合稿先拆成独立主体和动作，再归类，避免不同地区事项落在同一地区标签下。

两种规则均通过共享函数进入手动生成、流式生成、消息预览和自动周报。其他专题的消息不受影响；新增规则只影响以后生成的报告，不改写历史周报。

本地237项测试通过，覆盖真实路由和自动服务请求、官网材料、上下文身份边界、原有模板字节保留及其他专题隔离。隔离模型预览与边界案例证据保存在 `output/government-weekly-editorial-20261114/`；测试文件不写入生产报告历史、不发送通知。
