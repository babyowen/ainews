# 官微周报来源上下文

仅当本次报告专题为「江苏机关事务」、文章来源接口为 `极致了api`、微信长链接的账号身份存在于已核验清单时，在每篇新闻前独立附加发布账号、账号辖区和账号层级。标题、正文、已有短摘要和数据库字段保持原样。

`services/weeklyReportNews.cjs` 负责共享组装，手动三个生成入口（含流式）、后端消息预览、自动周报以及潜在客户模板均使用它。查询多读取已有的 `sourceapi` 列。短摘要和全文模式均携带来源上下文；正文少于500字而直接采用原文的文章也能获得地域背景。

来源规则只追加到含有匹配官微的当次模型 system 消息。所有现有 `config/` 提示词和 `config/runtime/` 自定义模板不改写、不保存新版本；未匹配账号和其他专题不追加规则。已有的日期规则处理保持原行为。新闻正文明确地点优先，转载和跨地区交流不得套用账号辖区，指代含糊时不猜测，也不从专题名称推断发生在江苏。

## 来源映射

`config/government-wechat-sources.json` 是采集端 `babyowen/serp_news` 的已核验清单及 `verified_source_context` 输出的只读版本快照，包含38个启用账号；停用的宁波号不在其中。文件记录源提交、清单路径和SHA-256、解析器版本及SHA-256。来源名单改变时，应从同一采集端注册表和解析器重新导出并审核，不能按昵称猜测或手写新增地区。周报运行时不跨服务器读取采集端。

匹配依赖 `mp.weixin.qq.com/s` 的唯一 `__biz`、`mid`、`idx` 参数；未知、停用或身份冲突的文章保持原处理方式。客户端提供的账号昵称、地区或 `source_context` 字段不用于建立映射。
